# AGY 工場自動化シミュレーター (Factory Automation Studio)

本格的な産業用オートメーション（FA）をブラウザ上で設計・体験できるリアルタイム工場シミュレーションWebアプリケーションです。

---

## 🚀 主な特徴

- **リアルタイム60FPSシミュレーション & インダストリアルUI**:
  - 素材供給からコンベア搬送、プレス成形、伸線加工、半導体エッチング、複数素材の自動組立、AI検査、仕分け、AGV無人搬送、出荷までをリアルタイムでシミュレーション。
- **多彩な産業用設備**:
  - 🏭 **マテリアル供給機 (Spawner)**: 鉄鉱石・銅鉱石・高純度シリコン・樹脂ペレットを自動供給。投入間隔や不良品混入率の調整可能。
  - ➡️ **ベルトコンベア (Conveyor)**: スムーズなアニメーションで部材を搬送。ドラッグ操作で直感的に連続敷設可能。
  - ⚙️ **精密加工機 (Processor)**: プレス加工（鉄板）、伸線加工（銅線）、半導体微細エッチング（ICチップ）、射出成形（筐体）を実行。
  - 🦾 **自動組立機 (Assembler)**: 複数ラインの部品を合流させ、「スマートIoTセンサー」「EVバッテリー」「協働ロボットコントローラ」を自動アセンブル。
  - 🔍 **AI画像品質検査スキャナー (Inspector)**: レーザースキャンで欠陥品（Defect）を瞬時にタグ付け。
  - 🔀 **スマートPLC分岐ソーター (Sorter)**: 「不良品のみ別ラインへ分岐」「特定部品の振り分け」などの条件分岐をGUIで設定可能。
  - 🚚 **無人搬送車 (AGV) システム**: 離れたエリア間を自動運転AGV台車が荷物を積載して往復搬送。
  - 📦 **出荷ドック (Exporter)**: 完成品を納品して資金を獲得。不良品を出荷するとペナルティ！
  - 🗑️ **廃棄ユニット (Trash)**: 不良品や不要部材を破砕・除去。
- **SCADA工場監視 & ボトルネック診断**:
  - 出荷スループット (ppm: 個/分)、総合生産効率スコア、稼働/待機/詰まりステータス、自動ボトルネック診断とアドバイス。
- **プリセット課題シナリオ & サンドボックス**:
  1. **入門**: 鉄板加工ラインの構築
  2. **課題1**: 不良品ゼロへの挑戦（AI検査＆PLCソーター自動仕分け）
  3. **課題2**: スマートIoTセンサー量産ライン（2系統ラインの同期・合流組立）
  4. **課題3**: AGV自動搬送スマートファクトリー（長距離ロボット物流統合）
  5. **メガファクトリー サンドボックス**: 無制限リソースでの自由設計
- **効果音エンジン (Web Audio API)**:
  - 外部ファイル不要のシンセサイズ効果音（配置音、出荷音、不良品アラート、クリアファンファーレ、ミュート機能付き）。

## 🛠️ 開発・起動方法

### 開発サーバーの起動 (Vite)
```bash
npm run dev
```
起動後、ブラウザで `http://localhost:5173`（またはCodespacesのポート転送URL）を開いてください。

### プロダクションビルド
```bash
npm run build
```

## 🎮 操作方法・ショートカットキー

| 操作 / キー | 機能 |
| :--- | :--- |
| **左クリック** | 設備の配置 / マシンの選択（選択ツール時） |
| **左ドラッグ** | コンベアの連続敷設（Factorioスタイル） |
| **右クリック** | 設備のクイック撤去 |
| **R キー** | 設備の向きを90度回転（上 / 右 / 下 / 左） |
| **Space キー** | シミュレーションの再生 / 一時停止 |
| **1 / 2 / 5 キー** | シミュレーション速度（1倍速 / 2倍速 / 5倍速） |
| **マウスホイール** | キャンバスのズームイン / ズームアウト |
| **Alt + ドラッグ (または 中ボタンドラッグ)** | 工場視点のパン（平行移動） |
| **Delete / Backspace** | 選択中の設備を撤去 |
| **Esc キー** | 選択解除 |
